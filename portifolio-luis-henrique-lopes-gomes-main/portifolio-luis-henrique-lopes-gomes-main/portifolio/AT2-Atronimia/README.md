# 🌌 Página Web de Astronomia e Exploração Espacial

## 📝 Descrição do Projeto

Este projeto consiste numa página web responsiva dedicada à temática de **Astronomia e Exploração Espacial**, concebida para apresentar conteúdos visuais e informativos sobre o cosmos, missões espaciais e corpos celestes de forma acessível e envolvente.

Desenvolvido como parte do portfólio acadêmico e pessoal, o projeto explora a estruturação semântica do HTML associada a folhas de estilo customizadas, priorizando o design responsivo, a estética imersiva e a boa experiência do utilizador (UX) em diferentes dispositivos.

## 🚀 Tecnologias Utilizadas

* **Estruturação:** HTML5 Semântico
* **Estilização:** CSS3 e Framework Bootstrap 5
* **Controle de Versão:** Git & GitHub
* **Hospedagem / Deploy:** GitHub Pages

## 📊 Resultados e Aprendizados

O desenvolvimento desta página permitiu aprimorar competências essenciais no desenvolvimento front-end:

* **Design Responsivo:** Aplicação de técnicas de layout adaptável para garantir uma visualização fluida tanto em computadores como em dispositivos móveis.
* **Organização de Assets:** Gestão estruturada de recursos visuais, pastas e arquivos estáticos para otimização do carregamento da página.
* **Deploy Automatizado:** Configuração e publicação do site diretamente na plataforma GitHub Pages, solucionando caminhos relativos de diretórios através do terminal.

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial (Gemini) estritamente como ferramenta de suporte tecnológico para o refinamento da estrutura semântica do código, sugestões de paletas de cores alinhadas com a temática espacial e depuração de estilos CSS. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
