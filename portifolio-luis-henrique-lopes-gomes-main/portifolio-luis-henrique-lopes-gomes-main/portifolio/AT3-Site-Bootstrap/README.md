# 🎨 Site Multi-Páginas com Bootstrap 5

## 📝 Descrição do Projeto

Este projeto consiste num site responsivo de múltiplas páginas desenvolvido com a utilização do framework **Bootstrap 5**, focado na criação de uma interface moderna, intuitiva e totalmente adaptável a diferentes tamanhos de ecrã.

Desenvolvido como atividade prática da disciplina de **Desenvolvimento Front-End para Web (2026.2)** da **Universidade Cidade de São Paulo (Unicid)**, o projeto explora a utilização de componentes pré-estilizados, grelhas flexíveis (*Grid System*) e utilitários do Bootstrap para construir uma navegação fluida e coerente.

## 🚀 Tecnologias Utilizadas

* **Estruturação:** HTML5 Semântico
* **Estilização & Layout:** CSS3 e Framework Bootstrap 5
* **Componentes:** Navbar, Cards, Modais, Footer e Grid System
* **Ambiente de Desenvolvimento:** Visual Studio Code
* **Hospedagem / Deploy:** GitHub Pages

## 📊 Resultados e Aprendizados

O desenvolvimento desta aplicação multi-páginas permitiu aprofundar competências práticas em design front-end responsivo:

* **Grid System:** Domínio sobre o sistema de colunas e pontos de interrupção (*breakpoints*) do Bootstrap para garantir compatibilidade móvel (Mobile First).
* **Consistência Visual:** Padronização de elementos visuais, esquemas de cores e tipografia ao longo de todas as páginas do site.
* **Componentização:** Integração eficiente de componentes interativos como menus de navegação colapsáveis, formulários estilizados e cartões informativos.

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial (Gemini) estritamente como ferramenta de suporte tecnológico para o auxílio na escolha das melhores estruturas de layout do Bootstrap 5, depuração de estilos personalizados e otimização da hierarquia de ficheiros. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
