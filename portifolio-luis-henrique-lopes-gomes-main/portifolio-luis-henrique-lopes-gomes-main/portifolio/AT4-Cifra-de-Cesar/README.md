# 🔐 Criptografia Matemática & Cifra de César em C

## 📝 Descrição do Projeto

Este projeto consiste no desenvolvimento de um software de criptografia matemática e processamento de dados estruturado em **linguagem C**. A aplicação combina o algoritmo clássico da **Cifra de César** com progressões numéricas (aritméticas e geométricas), sequências de Fibonacci e verificação de números primos para realizar a codificação e decodificação de mensagens textuais.

Desenvolvido como atividade prática das disciplinas do curso de **Análise e Desenvolvimento de Sistemas** da **Universidade Cidade de São Paulo (Unicid)**, o projeto explora a manipulação de fluxos de dados textuais, validação de entradas lógicas e gravação dinâmica de logs de saída em arquivos locais (`dados.txt` e `ordenado.txt`).

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C (Padrão C99/C11)
* **Estrutura Lógica:** Cifra de César + Progressões (PA/PG), Fibonacci e Números Primos
* **Manipulação de Arquivos:** I/O em C (`fopen`, `fprintf`, `fscanf`, `fclose`)
* **Ambiente de Desenvolvimento:** Visual Studio Code (Windows) & OnlineGDB
* **Controle de Versão:** Git & GitHub

## 📊 Resultados e Aprendizados

O desenvolvimento deste software permitiu consolidar conceitos essenciais de programação de baixo/médio nível e lógica matemática:

* **Manipulação de Ponteiros e Arquivos:** Leitura, processamento e gravação dinâmica de logs de execução e mensagens criptografadas em arquivos de texto locais.
* **Lógica Criptográfica Customizada:** Aplicação de deslocamentos alfabéticos baseados em fórmulas matemáticas progressivas para reforçar a segurança do algoritmo simples.
* **Tratamento de Fluxo de Dados:** Leitura, ordenação e exibição estruturada de strings e arrays de caracteres na linguagem C.
