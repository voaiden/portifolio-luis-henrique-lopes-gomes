# 🧮 Trabalho de Algoritmos e Lógica de Programação

## 📝 Descrição do Projeto

Este repositório reúne os algoritmos, estruturas de controle e resoluções de problemas desenvolvidos no âmbito das disciplinas práticas de **Algoritmos e Lógica de Programação** do curso de **Análise e Desenvolvimento de Sistemas** da **Universidade Cidade de São Paulo (Unicid)**.

O objetivo principal é a aplicação prática de conceitos fundamentais da ciência da computação, como manipulação de variáveis, estruturas condicionais, laços de repetição, vetores, matrizes, funções e manipulação básica de fluxos de entrada e saída em ambiente compilado.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C (Padrão C99/C11)
* **Ambiente de Desenvolvimento:** Visual Studio Code / OnlineGDB
* **Controle de Versão:** Git & GitHub

## 📊 Estrutura e Aprendizados

* **Lógica Computacional:** Desenvolvimento de raciocínio estruturado para a decomposição de problemas complexos em etapas menores e executáveis.
* **Validação de Dados:** Implementação de rotinas robustas para tratamento de entradas inválidas e garantia da integridade do fluxo de execução.
* **Organização de Código:** Manutenção de código limpo, comentado e em conformidade com as boas práticas de programação estruturada.

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial (Gemini) estritamente como suporte técnico para auxílio na depuração de erros de sintaxe, compreensão de estruturas lógicas e otimização de algoritmos. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
