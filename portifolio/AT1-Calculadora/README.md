# ⚖️ Calculadora de IMC Interativa

## 📝 Descrição do Projeto

Este projeto consiste em uma aplicação web interativa desenvolvida para realizar o cálculo do **Índice de Massa Corporal (IMC)** e classificar dinamicamente a faixa de saúde do usuário de acordo com os padrões da Organização Mundial da Saúde (OMS).

Desenvolvido como atividade prática da disciplina de **Desenvolvimento Front-End para Web (2026.2)** da **Universidade Cidade de São Paulo (Unicid)**, o projeto foca no uso de JavaScript para manipulação do DOM (Document Object Model), validação de formulários de entrada e execução de regras de negócio em tempo real.

## 🚀 Tecnologias Utilizadas

* **Estruturação:** HTML5 Semântico
* **Estilização:** CSS3 e Framework Bootstrap 5
* **Lógica e Dinamismo:** JavaScript (ES6+)
* **Ambiente de Desenvolvimento:** Visual Studio Code
* **Hospedagem / Deploy:** GitHub Pages

## 📊 Resultados e Aprendizados

O desenvolvimento deste projeto permitiu consolidar conceitos fundamentais do desenvolvimento web dinâmico no front-end:

* **Validação de Dados:** Implementação de verificações para garantir entradas numéricas válidas de altura e peso antes de executar a fórmula matemática.
* **Manipulação de DOM:** Atualização dinâmica dos elementos da tela sem a necessidade de recarregar a página (feedback imediato ao usuário).
* **Lógica de Categorização:** Construção de condicionais em JavaScript para enquadramento preciso do IMC nas categorias (Abaixo do peso, Peso normal, Sobrepeso e Graus de Obesidade).

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial (Gemini) estritamente como ferramenta de suporte tecnológico para depuração de funções lógicas em JavaScript, auxílio no refinamento das estruturas de validação e otimização da acessibilidade dos elementos visuais. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
